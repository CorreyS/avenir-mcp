This page takes you from nothing to a working avenir-mcp, in about ten minutes. Each step
ends with a check, so you know it worked before moving on.

<Steps>

1. [Install uv](#install-uv), the tool that runs avenir-mcp.
2. [Get a YNAB token](#get-a-ynab-token), avenir-mcp's access to your plans.
3. [Check that avenir-mcp starts](#check-that-avenir-mcp-starts), by hand, once.
4. [Add avenir-mcp to your client](#add-avenir-mcp-to-your-client).
5. [Check it works](#check-it-works) with a first question.
6. [Allow changes](#allow-changes), if you want the agent to tidy up for you.

</Steps>

<Aside type="tip" title="On Claude Desktop: one file, no terminal">
Claude Desktop installs avenir-mcp from an extension. It brings its own Python, keeps
your token where your system keeps passwords, and needs neither uv nor a configuration
file: steps 1 and 3 are not for you. Get [a YNAB token](#get-a-ynab-token), then follow
[Install the Claude Desktop extension](#install-the-claude-desktop-extension), which
spells every click out. **On Windows this is the way in**: nothing on this page asks you
to open a terminal.
</Aside>

## What you need

| | Why | Where to get it |
|---|---|---|
| **A YNAB account** | avenir-mcp reads and changes *your* plans | [app.ynab.com](https://app.ynab.com) |
| **An MCP client** | the application you talk to; it starts avenir-mcp | Claude Code, Claude Desktop, Cursor, VS Code… |
| **uv** | downloads and runs avenir-mcp, and the Python it needs, in an isolated environment | the next step |

You do **not** need to install Python, clone the repository or create a virtual
environment: uv does all of it.

October 2026). **With [this referral link](https://ynab.com/referral/?ref=refecMwMebD3KE6jt18&sponsor_name=Mathieu&utm_source=customer_referral) the trial lasts six weeks**, and if you
subscribe, you get a free month, and so does the author of avenir-mcp. It is a referral link:
the ordinary sign-up is at [ynab.com](https://www.ynab.com).

**Your bank.** YNAB imports transactions automatically from many banks: you see whether yours is
one when you add an account in YNAB ([in Europe](https://support.ynab.com/en_us/direct-import-in-europe-Syae1z_A9); [if your bank is not listed](https://support.ynab.com/en_us/my-bank-isnt-listed-HJivlLavle)).
Otherwise, import a file from your bank or enter transactions by hand. avenir-mcp works the
same either way: it reads YNAB, never your bank.
</Aside>

## Install uv

<Tabs syncKey="os">
  <TabItem label="macOS / Linux">
    In a terminal:
    ```bash
    curl -LsSf https://astral.sh/uv/install.sh | sh
    ```
    Or, with Homebrew: `brew install uv`.
  </TabItem>
  <TabItem label="Windows">
    In PowerShell:
    ```powershell
    powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
    ```
    Or, with WinGet: `winget install --id=astral-sh.uv -e`.
  </TabItem>
</Tabs>

**Close and reopen the terminal**, then check:

```bash
uv --version
```

It prints a version, such as `uv 0.12.19`. *Command not found*? The installer adds uv
to the `PATH` of new terminals only: open a new one. Details in
[uv's documentation](https://docs.astral.sh/uv/getting-started/installation/).

## Get a YNAB token

<Steps>

1. Sign in to YNAB **in a web browser** at [app.ynab.com](https://app.ynab.com) — the
   mobile apps do not show developer settings.
2. Click your name at the top left, then **Account Settings**.
3. Open **Developer Settings**.
4. Under **Personal Access Tokens**, click **New Token**, enter your YNAB password, then
   **Generate**.
5. Copy the token shown at the top of the page: a long string of letters, digits and
   dashes. **YNAB shows it only once.** If you lose it, create another and revoke the
   old one.

</Steps>

<Aside type="danger" title="Treat the token like a password">
A personal access token can **read and change every plan** of your account; YNAB
offers no read-only token. Never paste it into a chat with an AI, a shared file, an
issue or a repository. avenir-mcp never logs it and never returns it in an answer.
</Aside>

## Install the Claude Desktop extension

One file installs avenir-mcp, the Python it runs on and the settings it needs. There is
no terminal and no configuration file in this section, and no step of it is different on
Windows, macOS or Linux except where it says so.

<LinkButton href="https://github.com/mathbeal/avenir-mcp/releases/latest/download/avenir-mcp.mcpb" icon="download">Download for Claude Desktop</LinkButton>

The file is always the one of the newest release; which version it installs is written
inside it, and the steps below are the same whichever that is.

<Aside type="caution" title="The button gives a “Not Found” page?">
The release workflow attaches the extension, so a release published before that step of
the workflow existed carries none, and until the next release the link has nothing to
give. Install avenir-mcp by hand in the meantime, with the
[steps further down this page](#check-that-avenir-mcp-starts); the
[releases](https://github.com/mathbeal/avenir-mcp/releases) say under **Assets** which
files each one carries.
</Aside>

<Steps>

1. **Install Claude Desktop** if you have not already, from
   [claude.ai/download](https://claude.ai/download), and open it once.

2. **Download the extension** with the button above, or with
   [this link](https://github.com/mathbeal/avenir-mcp/releases/latest/download/avenir-mcp.mcpb).
   It weighs about 17 kB and goes to your **Downloads** folder as `avenir-mcp.mcpb`.

   On Windows, Edge or Chrome may say that the file *isn't commonly downloaded*. That
   warning is about how rare the file is, not about what is in it: click the three dots
   beside the download, then **Keep**. What you can check about the file instead is in
   [SECURITY.md](https://github.com/mathbeal/avenir-mcp/blob/main/SECURITY.md#the-claude-desktop-extension).

3. **Drag the file onto Settings → Extensions.** Open Claude Desktop, then
   **Settings → Extensions**: that screen lists the extensions you have, and it is where
   the file installs. Take `avenir-mcp.mcpb` from your Downloads folder, or from the
   browser's download list, and drop it on that screen. The install dialog opens.

   Double-clicking the file may work as well, if your system already opens `.mcpb` files
   with Claude Desktop. If instead Windows asks **which application to open the file
   with**, close that window: `.mcpb` files have no application associated with them,
   and searching for `claude.exe` finds nothing. Drag the file onto the **Extensions**
   screen instead.

   Neither works? On that same screen, open **Advanced settings** and, under **Extension
   Developer**, **Install Extension…**; pick the `.mcpb` from your Downloads folder.

4. **Install it.** The dialog names the extension, *avenir-mcp for YNAB*, and says what
   it does. Click **Install**.

5. **Paste your token** in **YNAB personal access token** — the one
   [from the step above](#get-a-ynab-token). `Ctrl` + `V` on Windows and Linux, `⌘` + `V`
   on macOS. The box hides it as you type; Claude Desktop keeps it where your system
   keeps passwords, and it is written in no file you can open.

6. **Leave *Allow changes to your plans* off**, then **Save**. avenir-mcp answers
   questions and changes nothing until you turn that on, which you can do at any time,
   in the same place.

7. **Check it is there.** **Settings → Extensions** lists **avenir-mcp for YNAB**, with
   its switch on.

8. **Ask it something.** In a new conversation: *“List my YNAB plans.”* Claude asks you
   to allow the tool the first time; allow it, and the answer names your plans. The very
   first answer takes a few seconds longer than the ones after it, while Claude Desktop
   fetches Python and avenir-mcp.

</Steps>

That is the whole installation. The rest of this page is for the other clients and for
installing by hand; skip to [your first conversation](/avenir-mcp/getting-started/first-conversation/),
or to [allow changes](#allow-changes) when you want the agent to tidy up for you.

<Aside type="note" title="Claude Desktop says the extension is not signed">
It is not: signing needs a code-signing certificate the project does not have. What you
can check instead, and what the file contains, is in
[SECURITY.md](https://github.com/mathbeal/avenir-mcp/blob/main/SECURITY.md#the-claude-desktop-extension).
An extension that fails to start is covered in
[Troubleshooting](/avenir-mcp/project/troubleshooting/).
</Aside>

| To | Do |
|---|---|
| **Change the token, or allow changes** | **Settings → Extensions → avenir-mcp for YNAB** |
| **Update** | [download the extension](https://github.com/mathbeal/avenir-mcp/releases/latest/download/avenir-mcp.mcpb) again and drop it on the **Settings → Extensions** screen, over the installed one; the link always gives the newest release |
| **Remove it** | **Settings → Extensions**, then remove it; the token goes with it |

## Check that avenir-mcp starts

Before configuring a client, run avenir-mcp once by hand. This downloads it and proves that
it starts.

<Tabs syncKey="os">
  <TabItem label="macOS / Linux">
    ```bash
    YNAB_API_KEY=your-token uvx avenir-mcp
    ```
  </TabItem>
  <TabItem label="Windows">
    ```powershell
    $env:YNAB_API_KEY = "your-token"; uvx avenir-mcp
    ```
  </TabItem>
</Tabs>

The first run downloads avenir-mcp and Python: a few seconds to a minute. Then **nothing is
printed and the command does not return** — that is expected: avenir-mcp waits for a client
to talk to it. Press **Ctrl+C** to stop it.

An error is printed instead? See [Troubleshooting](/avenir-mcp/project/troubleshooting/).

## Add avenir-mcp to your client

Pick your client. These configurations are **read-only**: avenir-mcp can answer questions
but change nothing. [Allow changes](#allow-changes) comes after. Cursor, LM Studio and
VS Code install it in one click, from the button at the top of their tab.

<Tabs syncKey="client">
  <TabItem label="Claude Code">
    In a terminal:
    ```bash
    claude mcp add avenir-mcp --scope user \
      --env YNAB_API_KEY=your-token \
      -- uvx avenir-mcp
    ```

    | Part | Meaning |
    |---|---|
    | `claude mcp add avenir-mcp` | register an MCP server named `avenir-mcp` |
    | `--scope user` | for all your projects; leave it out to register it for the current folder only |
    | `--env YNAB_API_KEY=…` | the environment avenir-mcp starts with |
    | `--` | what follows is the command that starts the server |
    | `uvx avenir-mcp` | that command |

    Claude Code keeps this, token included, in `~/.claude.json`, readable by you only.
  </TabItem>
  <TabItem label="Claude Desktop">
    **The extension** is the short way, and the one with no terminal:
    [Install the Claude Desktop extension](#install-the-claude-desktop-extension).

    **Or by hand**, if you would rather write the configuration yourself:

    1. Open Claude Desktop, then **Settings → Developer → Edit Config**. This opens
       `claude_desktop_config.json`:
       - macOS: `~/Library/Application Support/Claude/claude_desktop_config.json`
       - Windows: `%APPDATA%\Claude\claude_desktop_config.json`
    2. If the file is empty, paste all of this. If it already lists servers, add only
       the `"avenir-mcp": { … }` block inside the existing `mcpServers`, with a comma after
       the previous entry.
       ```json
       {
         "mcpServers": {
           "avenir-mcp": {
             "command": "uvx",
             "args": ["avenir-mcp"],
             "env": { "YNAB_API_KEY": "your-token" }
           }
         }
       }
       ```
    3. Save, then **quit Claude Desktop completely** — ⌘Q on macOS, or from the tray
       icon on Windows — and reopen it.
  </TabItem>
  <TabItem label="Cursor">
    <LinkButton href={links.cursor} icon="right-arrow">Install in Cursor</LinkButton>

    1. Click the button: Cursor asks you to confirm, then adds `avenir-mcp` to its servers.
    2. Open **Cursor Settings → MCP**, replace `your-token` with the token you copied,
       and check that `avenir-mcp` is switched on.

    Or by hand: create or open `~/.cursor/mcp.json` (all projects) or `.cursor/mcp.json`
    in a project, and add:
    ```json
    {
      "mcpServers": {
        "avenir-mcp": {
          "command": "uvx",
          "args": ["avenir-mcp"],
          "env": { "YNAB_API_KEY": "your-token" }
        }
      }
    }
    ```
  </TabItem>
  <TabItem label="VS Code">
    <LinkButton href={links.vs_code} icon="right-arrow">Install in VS Code</LinkButton>

    1. Click the button: VS Code asks you to confirm, then asks for your token in a
       password box and keeps it in its own secret storage.
    2. Use avenir-mcp from Copilot Chat in **Agent** mode.

    Or by hand: create `.vscode/mcp.json` in your workspace. VS Code asks for the token
    there too, so the file never holds it: a file of a workspace is easy to add to a
    repository by mistake.
    ```json
    {
      "inputs": [
        {
          "type": "promptString",
          "id": "ynab-token",
          "description": "YNAB personal access token",
          "password": true
        }
      ],
      "servers": {
        "avenir-mcp": {
          "type": "stdio",
          "command": "uvx",
          "args": ["avenir-mcp"],
          "env": { "YNAB_API_KEY": "${input:ynab-token}" }
        }
      }
    }
    ```
    Then run the command **MCP: List Servers**, select `avenir-mcp`, then **Start Server**.
  </TabItem>
  <TabItem label="Gemini CLI">
    1. Open `~/.gemini/settings.json` (create it if needed) and add:
       ```json
       {
         "mcpServers": {
           "avenir-mcp": {
             "command": "uvx",
             "args": ["avenir-mcp"],
             "env": { "YNAB_API_KEY": "your-token" }
           }
         }
       }
       ```
    2. Start `gemini` and type `/mcp`: `avenir-mcp` is listed with its tools. The model is the one Gemini CLI uses.
  </TabItem>
  <TabItem label="Codex CLI">
    1. Open `~/.codex/config.toml` (create it if needed) and add:
       ```toml
       [mcp_servers.avenir]
       command = "uvx"
       args = ["avenir-mcp"]
       env = { YNAB_API_KEY = "your-token" }
       ```
    2. Start `codex` and type `/mcp`: `avenir-mcp` is listed with its tools. The model is the one Codex uses.
  </TabItem>
  <TabItem label="LM Studio">
    <LinkButton href={links.lm_studio} icon="right-arrow">Add to LM Studio</LinkButton>

    For a model running on your own machine — see [Choose a model](/avenir-mcp/guides/choose-a-model/#local-models).

    1. Click the button: LM Studio asks you to confirm, then adds `avenir-mcp` to its `mcp.json`.
    2. Open the **Program** tab of the right-hand sidebar, then **Install → Edit mcp.json**,
       and replace `your-token` with the token you copied.
    3. Save, load a model that supports tool use, and start a chat: LM Studio asks before each tool call.

    Or by hand: add this to the same `mcp.json`:
    ```json
    {
      "mcpServers": {
        "avenir-mcp": {
          "command": "uvx",
          "args": ["avenir-mcp"],
          "env": { "YNAB_API_KEY": "your-token" }
        }
      }
    }
    ```
  </TabItem>
  <TabItem label="Other clients">
    Any MCP client that starts servers over **stdio** works. Give it:

    | Setting | Value |
    |---|---|
    | command | `uvx` |
    | arguments | `avenir-mcp` |
    | environment | `YNAB_API_KEY` = your token |

    To run it in a container instead, build the image from the `Dockerfile` at the root
    of the repository with `docker build -t avenir-mcp .`, then give the client `docker`
    as the command and `run -i --rm -e YNAB_API_KEY avenir-mcp` as the arguments, so
    that the token travels in the environment rather than on a command line.

    For clients that connect to a URL instead, see
    [Run over HTTP](/avenir-mcp/guides/run-options/#run-over-http).
  </TabItem>
</Tabs>

<Aside type="tip" title="“uvx not found” in a desktop application">
Graphical applications do not always see the `PATH` of your terminal. If the client
cannot find `uvx`, replace `"uvx"` with its full path, given by `which uvx` (macOS,
Linux) or `where uvx` (Windows) — for instance `"/Users/<you>/.local/bin/uvx"`.
</Aside>

## Allow changes

To let the agent classify transactions, move money between categories or reconcile
accounts, add `AVENIR_MCP_WRITE=1` to avenir-mcp's environment.

<Tabs syncKey="client">
  <TabItem label="Claude Desktop">
    Installed from the extension: open **Settings → Extensions → avenir-mcp for YNAB**,
    turn **Allow changes to your plans** on, save, and restart Claude Desktop. The
    extension sets the variable for you, so there is nothing to type.
  </TabItem>
  <TabItem label="Claude Code">
    Remove avenir-mcp and add it again with the extra variable:
    ```bash
    claude mcp remove avenir-mcp --scope user
    claude mcp add avenir-mcp --scope user \
      --env YNAB_API_KEY=your-token \
      --env AVENIR_MCP_WRITE=1 \
      -- uvx avenir-mcp
    ```
  </TabItem>
  <TabItem label="JSON configurations">
    Add the variable next to the token, save, then restart the client:
    ```json
    "env": { "YNAB_API_KEY": "your-token", "AVENIR_MCP_WRITE": "1" }
    ```
  </TabItem>
  <TabItem label="Codex CLI (TOML)">
    Add the variable next to the token in `~/.codex/config.toml`, then restart Codex:
    ```toml
    env = { YNAB_API_KEY = "your-token", AVENIR_MCP_WRITE = "1" }
    ```
  </TabItem>
</Tabs>

The value must be exactly `1`. Check: the client now lists **33** tools instead of 19.

| | Read-only (default) | With `AVENIR_MCP_WRITE=1` |
|---|---|---|
| Tools listed | 19 | 33 |
| Classify, budget, reconcile, create | — | previewed, confirmed by you, undoable |
| If the agent misunderstands | nothing can change | a change you confirmed, which you can undo |

<Aside type="caution" title="If your client cannot ask you">
Some clients cannot put a question to you (MCP elicitation). avenir-mcp then gives the agent
a single-use code, and it is up to the agent to show you the changes and wait for your yes.
In [our evaluation](/avenir-mcp/project/evaluation/), one model out of eight, misled by a memo
planted in a transaction, used such a code on its own, then undid its change. So that only
you can confirm, add `AVENIR_MCP_REQUIRE_ELICITATION=1` if your client supports elicitation:
codes are then disabled.
</Aside>

Every change is shown to you before it is applied: see
[Safety by design](/avenir-mcp/concepts/safety/).

## Update, remove, revoke

| To | Do |
|---|---|
| **Update** | `uvx` fetches new releases by itself from time to time; force it with `uvx --refresh avenir-mcp`. The Claude Desktop extension is updated by [downloading it](https://github.com/mathbeal/avenir-mcp/releases/latest/download/avenir-mcp.mcpb) again and dropping it on the **Settings → Extensions** screen, over the installed one |
| **Remove** | `claude mcp remove avenir-mcp --scope user`, or delete the `avenir-mcp` entry from the client's configuration. The extension is removed from **Settings → Extensions**, token included |
| **Clean up** | avenir-mcp's only file on your machine is its [journal](/avenir-mcp/concepts/journal/), in `~/.local/state/avenir-mcp/` |
| **Revoke the token** | YNAB → Account Settings → Developer Settings → **Revoke** next to the token |
