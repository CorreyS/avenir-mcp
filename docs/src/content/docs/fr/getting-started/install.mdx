Cette page vous mène de zéro à avenir-mcp qui fonctionne, en une dizaine de minutes. Chaque
étape se termine par une vérification : vous savez qu'elle a marché avant de passer à
la suivante.

<Steps>

1. [Installer uv](#installer-uv), l'outil qui lance avenir-mcp.
2. [Obtenir un jeton YNAB](#obtenir-un-jeton-ynab), l'accès d'avenir-mcp à vos plans.
3. [Premier lancement à la main](#premier-lancement-à-la-main), une seule fois.
4. [Ajouter avenir-mcp à votre client](#ajouter-avenir-mcp-à-votre-client).
5. [Vérifier que tout fonctionne](#vérifier-que-tout-fonctionne) avec une première question.
6. [Autoriser les modifications](#autoriser-les-modifications), si vous voulez que l'agent range pour vous.

</Steps>

<Aside type="tip" title="Sur Claude Desktop : un seul fichier, pas de terminal">
Claude Desktop installe avenir-mcp à partir d'une extension. Elle apporte son propre
Python, garde votre jeton là où votre système conserve les mots de passe, et ne demande
ni uv ni fichier de configuration : les étapes 1 et 3 ne vous concernent pas. Commencez
par obtenir [un jeton YNAB](#obtenir-un-jeton-ynab), puis suivez
[Installer l'extension Claude Desktop](#installer-lextension-claude-desktop), qui
détaille chaque clic. **Sous Windows, c'est la marche à suivre**, et rien sur cette page
ne vous demande d'ouvrir un terminal.
</Aside>

## Ce qu'il vous faut

| | Pourquoi | Où l'obtenir |
|---|---|---|
| **Un compte YNAB** | avenir-mcp lit et modifie *vos* plans | [app.ynab.com](https://app.ynab.com) |
| **Un client MCP** | l'application avec laquelle vous parlez ; c'est elle qui lance avenir-mcp | Claude Code, Claude Desktop, Cursor, VS Code… |
| **uv** | télécharge et lance avenir-mcp, et le Python dont il a besoin, dans un environnement isolé | l'étape suivante |

Vous n'avez **pas** besoin d'installer Python, de cloner le dépôt ni de créer un
environnement virtuel : uv s'en charge.

jusqu'à six personnes (tarifs d'octobre 2026). **Avec [ce lien de parrainage](https://ynab.com/referral/?ref=refecMwMebD3KE6jt18&sponsor_name=Mathieu&utm_source=customer_referral), l'essai
dure six semaines**, et si vous vous abonnez, vous obtenez un mois offert, tout comme l'auteur
d'avenir-mcp. C'est un lien de parrainage : l'inscription ordinaire se fait sur

**Votre banque.** YNAB importe automatiquement les opérations de nombreuses banques : vous voyez
si la vôtre en fait partie en ajoutant un compte dans YNAB ([en Europe](https://support.ynab.com/en_us/direct-import-in-europe-Syae1z_A9) ;

les opérations. avenir-mcp fonctionne de la même façon dans les deux cas : il lit YNAB, jamais
votre banque.
</Aside>

## Installer uv

<Tabs syncKey="os">
  <TabItem label="macOS / Linux">
    Dans un terminal :
    ```bash
    curl -LsSf https://astral.sh/uv/install.sh | sh
    ```
    Ou, avec Homebrew : `brew install uv`.
  </TabItem>
  <TabItem label="Windows">
    Dans PowerShell :
    ```powershell
    powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
    ```
    Ou, avec WinGet : `winget install --id=astral-sh.uv -e`.
  </TabItem>
</Tabs>

**Fermez et rouvrez le terminal**, puis vérifiez :

```bash
uv --version
```

Une version s'affiche, par exemple `uv 0.12.19`. *Commande introuvable* ? L'installeur
ajoute uv au `PATH` des nouveaux terminaux seulement : ouvrez-en un nouveau. Détails dans
la [documentation d'uv](https://docs.astral.sh/uv/getting-started/installation/).

## Obtenir un jeton YNAB

<Steps>

1. Connectez-vous à YNAB **dans un navigateur**, sur [app.ynab.com](https://app.ynab.com)
   — les applications mobiles n'affichent pas les réglages développeur.
2. Cliquez sur votre nom en haut à gauche, puis **Account Settings**.
3. Ouvrez **Developer Settings**.
4. Sous **Personal Access Tokens**, cliquez sur **New Token**, saisissez votre mot de
   passe YNAB, puis **Generate**.
5. Copiez le jeton affiché en haut de la page : une longue suite de lettres, de chiffres
   et de tirets. **YNAB ne l'affiche qu'une fois.** Si vous le perdez, créez-en un autre
   et révoquez l'ancien.

</Steps>

<Aside type="danger" title="Traitez le jeton comme un mot de passe">
Un jeton d'accès personnel peut **lire et modifier tous les plans** de votre compte ;
YNAB ne propose pas de jeton en lecture seule. Ne le collez jamais dans une conversation
avec une IA, un fichier partagé, une issue ou un dépôt. avenir-mcp ne le journalise jamais et
ne le renvoie jamais dans une réponse.
</Aside>

## Installer l'extension Claude Desktop

Un seul fichier installe avenir-mcp, le Python sur lequel il tourne et les réglages dont
il a besoin. Cette section ne comporte ni terminal ni fichier de configuration, et
aucune de ses étapes ne diffère entre Windows, macOS et Linux, sauf là où elle le dit.

<LinkButton href="https://github.com/mathbeal/avenir-mcp/releases/latest/download/avenir-mcp.mcpb" icon="download">Télécharger pour Claude Desktop</LinkButton>

Le fichier correspond toujours à la dernière version disponible ; la version qu'il
installe est indiquée dans le fichier lui-même, et les étapes ci-dessous sont les mêmes
quelle que soit cette version.

<Aside type="caution" title="Le bouton affiche-t-il une page « Not Found » ?">
Le workflow de publication intègre l'extension ; par conséquent, une version publiée
avant que cette étape du workflow n'existe n'en contient aucune, et jusqu'à la prochaine
version, le lien ne mène nulle part. En attendant, installez avenir-mcp manuellement en
suivant les [étapes indiquées plus bas sur cette page](#premier-lancement-à-la-main) ; la
section **Assets** de chaque [version](https://github.com/mathbeal/avenir-mcp/releases)
précise les fichiers qu'elle contient.
</Aside>

<Steps>

1. **Installez Claude Desktop**, si ce n'est pas déjà fait, depuis
   [claude.ai/download](https://claude.ai/download), et lancez-le une fois.

2. **Téléchargez l'extension** à l'aide du bouton ci-dessus ou via
   [ce lien](https://github.com/mathbeal/avenir-mcp/releases/latest/download/avenir-mcp.mcpb).
   Elle pèse environ 17 ko et sera enregistrée dans votre dossier de téléchargements sous
   le nom `avenir-mcp.mcpb`.

   Sous Windows, Edge ou Chrome peuvent vous avertir que le fichier n'est pas couramment
   téléchargé. Cet avertissement porte sur la rareté du fichier, non sur son contenu :
   cliquez sur les trois points à côté du téléchargement, puis sur **Keep**. Ce que vous
   pouvez vérifier du fichier à la place est écrit dans
   [SECURITY.md](https://github.com/mathbeal/avenir-mcp/blob/main/SECURITY.md#the-claude-desktop-extension).

3. **Faites glisser le fichier vers Settings → Extensions.** Ouvrez Claude Desktop,
   puis **Settings → Extensions** : cet écran répertorie les extensions dont vous
   disposez, et c'est là que le fichier s'installe. Sélectionnez le fichier
   `avenir-mcp.mcpb` dans votre dossier de téléchargements ou dans la liste des
   téléchargements de votre navigateur, puis faites-le glisser sur cet écran. La boîte de
   dialogue d'installation s'ouvre.

   Un double-clic sur le fichier peut également fonctionner, si votre système ouvre déjà
   les fichiers `.mcpb` avec Claude Desktop. Si, au contraire, Windows vous demande
   **avec quelle application ouvrir le fichier**, fermez cette fenêtre : les fichiers
   `.mcpb` ne sont associés à aucune application, et la recherche de `claude.exe` ne
   donne aucun résultat. Faites plutôt glisser le fichier sur l'écran **Extensions**.

   Aucune des deux ne fonctionne ? Sur ce même écran, ouvrez les **Advanced settings**
   puis, sous **Extension Developer**, cliquez sur **Install Extension…** ; sélectionnez
   le fichier dans votre dossier de téléchargements.

4. **Installez-la.** La boîte de dialogue donne le nom de l'extension,
   *avenir-mcp for YNAB*, et dit ce qu'elle fait. Cliquez sur **Install**.

5. **Collez votre jeton** dans le champ nommé **YNAB personal access token**, celui
   [de l'étape précédente](#obtenir-un-jeton-ynab). `Ctrl` + `V` sous Windows et Linux,
   `⌘` + `V` sur macOS. Le champ masque ce que vous y collez ;
   Claude Desktop le garde là où votre système conserve les mots de passe, et il n'est
   écrit dans aucun fichier que vous pourriez ouvrir.

6. **Laissez la case *Allow changes to your plans* décochée**, puis enregistrez.
   avenir-mcp répond aux questions et ne modifie rien tant que cette case reste décochée.
   Vous pourrez la cocher plus tard, au même endroit.

7. **Vérifiez qu'elle est bien là.** **Settings → Extensions** affiche désormais
   **avenir-mcp for YNAB**, activée.

8. **Posez-lui une question.** Dans une nouvelle conversation, écrivez :
   *« Liste mes plans YNAB. »* Claude vous demande d'autoriser l'outil la première fois ;
   autorisez-le, et la réponse donne les noms de vos plans. La toute première réponse
   prend quelques secondes de plus que les suivantes, le temps que Claude Desktop
   récupère Python et avenir-mcp.

</Steps>

L'installation est terminée. La suite de cette page traite des autres clients et de
l'installation à la main ; continuez avec
[votre première conversation](/avenir-mcp/fr/getting-started/first-conversation/), ou
avec [autoriser les modifications](#autoriser-les-modifications) si vous voulez que
l'agent range pour vous.

<Aside type="note" title="Claude Desktop dit que l'extension n'est pas signée">
Elle ne l'est pas : signer demande un certificat de signature de code dont le projet ne
dispose pas. Ce que le fichier contient, et ce que vous pouvez vérifier à la place, est
écrit dans
[SECURITY.md](https://github.com/mathbeal/avenir-mcp/blob/main/SECURITY.md#the-claude-desktop-extension).
Le cas d'une extension qui ne démarre pas est traité dans le
[dépannage](/avenir-mcp/fr/project/troubleshooting/).
</Aside>

| Pour | Faire |
|---|---|
| **Changer le jeton, ou autoriser les modifications** | **Settings → Extensions → avenir-mcp for YNAB** |
| **Mettre à jour** | [téléchargez à nouveau l'extension](https://github.com/mathbeal/avenir-mcp/releases/latest/download/avenir-mcp.mcpb) et ouvrez-la par-dessus celle qui est déjà installée ; le lien renvoie toujours vers la dernière version disponible |
| **Retirer** | retirez-la depuis **Settings → Extensions** ; le jeton part avec elle |

## Premier lancement à la main

Avant de configurer un client, lancez avenir-mcp une fois à la main. Cela le télécharge et
prouve qu'il démarre.

<Tabs syncKey="os">
  <TabItem label="macOS / Linux">
    ```bash
    YNAB_API_KEY=votre-jeton uvx avenir-mcp
    ```
  </TabItem>
  <TabItem label="Windows">
    ```powershell
    $env:YNAB_API_KEY = "votre-jeton"; uvx avenir-mcp
    ```
  </TabItem>
</Tabs>

Le premier lancement télécharge avenir-mcp et Python : de quelques secondes à une minute.
Ensuite **rien ne s'affiche et la commande ne rend pas la main** — c'est normal : avenir-mcp
attend qu'un client lui parle. Appuyez sur **Ctrl+C** pour l'arrêter.

Une erreur s'affiche à la place ? Voir le [dépannage](/avenir-mcp/fr/project/troubleshooting/).

## Ajouter avenir-mcp à votre client

Choisissez votre client. Ces configurations sont **en lecture seule** : avenir-mcp répond
aux questions mais ne modifie rien. [Autoriser les modifications](#autoriser-les-modifications)
vient après. Cursor, LM Studio et VS Code permettent de l'installer en un seul clic, à
partir du bouton situé en haut de leur onglet.

<Tabs syncKey="client">
  <TabItem label="Claude Code">
    Dans un terminal :
    ```bash
    claude mcp add avenir-mcp --scope user \
      --env YNAB_API_KEY=votre-jeton \
      -- uvx avenir-mcp
    ```

    | Élément | Sens |
    |---|---|
    | `claude mcp add avenir-mcp` | enregistre un serveur MCP nommé `avenir-mcp` |
    | `--scope user` | pour tous vos projets ; sans lui, seulement pour le dossier courant |
    | `--env YNAB_API_KEY=…` | l'environnement avec lequel avenir-mcp démarre |
    | `--` | ce qui suit est la commande qui lance le serveur |
    | `uvx avenir-mcp` | cette commande |

    Claude Code garde cela, jeton compris, dans `~/.claude.json`, lisible par vous seul.
  </TabItem>
  <TabItem label="Claude Desktop">
    **L'extension** est la voie courte, et celle qui ne demande pas de terminal :
    [Installer l'extension Claude Desktop](#installer-lextension-claude-desktop).

    **Ou à la main**, si vous préférez écrire la configuration vous-même :

    1. Ouvrez Claude Desktop, puis **Settings → Developer → Edit Config**. Cela ouvre
       `claude_desktop_config.json` :
       - macOS : `~/Library/Application Support/Claude/claude_desktop_config.json`
       - Windows : `%APPDATA%\Claude\claude_desktop_config.json`
    2. Si le fichier est vide, collez tout ceci. S'il liste déjà des serveurs, ajoutez
       seulement le bloc `"avenir-mcp": { … }` dans le `mcpServers` existant, avec une
       virgule après l'entrée précédente.
       ```json
       {
         "mcpServers": {
           "avenir-mcp": {
             "command": "uvx",
             "args": ["avenir-mcp"],
             "env": { "YNAB_API_KEY": "votre-jeton" }
           }
         }
       }
       ```
    3. Enregistrez, puis **quittez complètement Claude Desktop** — ⌘Q sur macOS, ou
       depuis l'icône de la barre des tâches sous Windows — et rouvrez-le.
  </TabItem>
  <TabItem label="Cursor">
    <LinkButton href={links.cursor} icon="right-arrow">Installer dans Cursor</LinkButton>

    1. Cliquez sur le bouton : Cursor vous demande de confirmer, puis ajoute `avenir-mcp`
       à sa liste de serveurs.
    2. Ouvrez **Cursor Settings → MCP**, remplacez `votre-jeton` par le jeton que vous
       avez copié, et vérifiez que `avenir-mcp` est activé.

    Ou à la main : créez ou ouvrez `~/.cursor/mcp.json` (tous les projets) ou
    `.cursor/mcp.json` dans un projet, et ajoutez :
    ```json
    {
      "mcpServers": {
        "avenir-mcp": {
          "command": "uvx",
          "args": ["avenir-mcp"],
          "env": { "YNAB_API_KEY": "votre-jeton" }
        }
      }
    }
    ```
  </TabItem>
  <TabItem label="VS Code">
    <LinkButton href={links.vs_code} icon="right-arrow">Installer dans VS Code</LinkButton>

    1. Cliquez sur le bouton : VS Code vous demande de confirmer, puis vous invite à
       saisir votre jeton dans un champ de mot de passe et le conserve dans son propre
       espace de stockage sécurisé.
    2. Utilisez-le dans Copilot Chat en mode **Agent**.

    Ou à la main : créez `.vscode/mcp.json` dans votre espace de travail. VS Code demande
    également le jeton à cet endroit ; le fichier ne le contient donc jamais : un fichier
    d'un espace de travail peut facilement être ajouté par erreur à un dépôt.
    ```json
    {
      "inputs": [
        {
          "type": "promptString",
          "id": "ynab-token",
          "description": "Jeton d'accès personnel YNAB",
          "password": true
        }
      ],
      "servers": {
        "avenir-mcp": {
          "type": "stdio",
          "command": "uvx",
          "args": ["avenir-mcp"],
          "env": { "YNAB_API_KEY": "${input:ynab-token}" }
        }
      }
    }
    ```
    Exécutez ensuite la commande **MCP: List Servers**, choisissez `avenir-mcp`, puis
    **Start Server**.
  </TabItem>
  <TabItem label="Gemini CLI">
    1. Ouvrez `~/.gemini/settings.json` (créez-le si besoin) et ajoutez :
       ```json
       {
         "mcpServers": {
           "avenir-mcp": {
             "command": "uvx",
             "args": ["avenir-mcp"],
             "env": { "YNAB_API_KEY": "votre-jeton" }
           }
         }
       }
       ```
    2. Lancez `gemini` et tapez `/mcp` : `avenir-mcp` apparaît avec ses outils. Le modèle est celui qu'utilise Gemini CLI.
  </TabItem>
  <TabItem label="Codex CLI">
    1. Ouvrez `~/.codex/config.toml` (créez-le si besoin) et ajoutez :
       ```toml
       [mcp_servers.avenir]
       command = "uvx"
       args = ["avenir-mcp"]
       env = { YNAB_API_KEY = "votre-jeton" }
       ```
    2. Lancez `codex` et tapez `/mcp` : `avenir-mcp` apparaît avec ses outils. Le modèle est celui qu'utilise Codex.
  </TabItem>
  <TabItem label="LM Studio">
    <LinkButton href={links.lm_studio} icon="right-arrow">Ajouter à LM Studio</LinkButton>

    Pour un modèle qui tourne sur votre propre machine — voir [Choisir un modèle](/avenir-mcp/fr/guides/choose-a-model/#modèles-locaux).

    1. Cliquez sur le bouton : LM Studio vous demande de confirmer, puis ajoute `avenir-mcp` à son fichier `mcp.json`.
    2. Dans LM Studio, ouvrez l'onglet **Program** de la barre latérale droite, puis **Install → Edit mcp.json**, et remplacez `votre-jeton` par le jeton que vous avez copié.
    3. Enregistrez, chargez un modèle qui gère l'appel d'outils, et ouvrez une conversation : LM Studio demande avant chaque appel d'outil.

    Ou manuellement : ajoutez ceci dans le même fichier `mcp.json` :
    ```json
    {
      "mcpServers": {
        "avenir-mcp": {
          "command": "uvx",
          "args": ["avenir-mcp"],
          "env": { "YNAB_API_KEY": "votre-jeton" }
        }
      }
    }
    ```
  </TabItem>
  <TabItem label="Autres clients">
    Tout client MCP qui lance ses serveurs en **stdio** fonctionne. Indiquez-lui :

    | Réglage | Valeur |
    |---|---|
    | commande | `uvx` |
    | arguments | `avenir-mcp` |
    | environnement | `YNAB_API_KEY` = votre jeton |

    Pour les clients qui se connectent à une URL, voir
    [Lancer en HTTP](/avenir-mcp/fr/guides/run-options/#lancer-en-http).
  </TabItem>
</Tabs>

<Aside type="tip" title="« uvx introuvable » dans une application de bureau">
Les applications graphiques ne voient pas toujours le `PATH` de votre terminal. Si le
client ne trouve pas `uvx`, remplacez `"uvx"` par son chemin complet, donné par
`which uvx` (macOS, Linux) ou `where uvx` (Windows) — par exemple
`"/Users/<vous>/.local/bin/uvx"`.
</Aside>

## Autoriser les modifications

Pour que l'agent puisse classer des transactions, déplacer de l'argent entre catégories
ou rapprocher des comptes, ajoutez `AVENIR_MCP_WRITE=1` à l'environnement d'avenir-mcp.

<Tabs syncKey="client">
  <TabItem label="Claude Desktop">
    Installée depuis l'extension : ouvrez
    **Settings → Extensions → avenir-mcp for YNAB**, cochez
    **Allow changes to your plans**, enregistrez, et redémarrez Claude Desktop.
    L'extension pose la variable pour vous, il n'y a rien à taper.
  </TabItem>
  <TabItem label="Claude Code">
    Retirez avenir-mcp et ajoutez-le à nouveau avec la variable en plus :
    ```bash
    claude mcp remove avenir-mcp --scope user
    claude mcp add avenir-mcp --scope user \
      --env YNAB_API_KEY=votre-jeton \
      --env AVENIR_MCP_WRITE=1 \
      -- uvx avenir-mcp
    ```
  </TabItem>
  <TabItem label="Configurations JSON">
    Ajoutez la variable à côté du jeton, enregistrez, puis redémarrez le client :
    ```json
    "env": { "YNAB_API_KEY": "votre-jeton", "AVENIR_MCP_WRITE": "1" }
    ```
  </TabItem>
  <TabItem label="Codex CLI (TOML)">
    Ajoutez la variable à côté du jeton dans `~/.codex/config.toml`, puis relancez Codex :
    ```toml
    env = { YNAB_API_KEY = "votre-jeton", AVENIR_MCP_WRITE = "1" }
    ```
  </TabItem>
</Tabs>

La valeur doit être exactement `1`. Vérification : le client liste maintenant **33**
outils au lieu de 19.

| | Lecture seule (défaut) | Avec `AVENIR_MCP_WRITE=1` |
|---|---|---|
| Outils listés | 19 | 33 |
| Classer, budgéter, rapprocher, créer | — | prévisualisé, confirmé par vous, annulable |
| Si l'agent comprend mal | rien ne peut changer | un changement que vous avez confirmé, et que vous pouvez annuler |

<Aside type="caution" title="Si votre client ne sait pas vous poser la question">
Certains clients ne savent pas vous poser une question (l'élicitation MCP). avenir-mcp remet
alors à l'agent un code à usage unique, et c'est à l'agent de vous montrer les changements et
d'attendre votre oui. Dans [notre évaluation](/avenir-mcp/fr/project/evaluation/), un modèle
sur huit, trompé par un mémo glissé dans une transaction, s'est servi de lui-même d'un tel code,
puis a annulé son changement. Pour que vous seul puissiez confirmer, ajoutez
`AVENIR_MCP_REQUIRE_ELICITATION=1` si votre client gère l'élicitation : les codes sont
alors désactivés.
</Aside>

Chaque changement vous est montré avant d'être appliqué : voir
[Sécurité par conception](/avenir-mcp/fr/concepts/safety/).

## Mettre à jour, retirer, révoquer

| Pour | Faire |
|---|---|
| **Mettre à jour** | `uvx` récupère les nouvelles versions de lui-même de temps en temps ; forcez-le avec `uvx --refresh avenir-mcp`. Pour mettre à jour l'extension Claude Desktop, il suffit de [la télécharger à nouveau](https://github.com/mathbeal/avenir-mcp/releases/latest/download/avenir-mcp.mcpb) et de l'ouvrir par-dessus celle qui est déjà installée |
| **Retirer** | `claude mcp remove avenir-mcp --scope user`, ou supprimez l'entrée `avenir-mcp` de la configuration du client. L'extension se retire depuis **Settings → Extensions**, jeton compris |
| **Nettoyer** | le seul fichier d'avenir-mcp sur votre machine est son [journal](/avenir-mcp/fr/concepts/journal/), dans `~/.local/state/avenir-mcp/` |
| **Révoquer le jeton** | YNAB → Account Settings → Developer Settings → **Revoke** à côté du jeton |
