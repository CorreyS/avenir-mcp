Diese Seite führt Sie in etwa zehn Minuten von null zu einem funktionierenden avenir-mcp.
Jeder Schritt endet mit einer Prüfung, damit Sie wissen, dass er geklappt hat, bevor Sie
weitermachen.

<Steps>

1. [uv installieren](#uv-installieren), das Tool, das avenir-mcp ausführt.
2. [Ein YNAB-Token besorgen](#ein-ynab-token-besorgen), den Zugang von avenir-mcp zu Ihren Plans.
3. [Prüfen, ob avenir-mcp startet](#prüfen-ob-avenir-mcp-startet), einmal von Hand.
4. [avenir-mcp zu Ihrem Client hinzufügen](#avenir-mcp-zu-ihrem-client-hinzufügen).
5. [Prüfen, ob es funktioniert](#prüfen-ob-es-funktioniert), mit einer ersten Frage.
6. [Änderungen erlauben](#änderungen-erlauben), wenn der Agent für Sie aufräumen soll.

</Steps>

<Aside type="tip" title="Unter Claude Desktop: eine Datei, kein Terminal">
Claude Desktop installiert avenir-mcp über eine Erweiterung. Sie bringt ihr eigenes
Python mit, verwahrt Ihr Token dort, wo Ihr System Passwörter verwahrt, und braucht
weder uv noch eine Konfigurationsdatei: die Schritte 1 und 3 betreffen Sie nicht.
Besorgen Sie sich zuerst [ein YNAB-Token](#ein-ynab-token-besorgen), und folgen Sie dann
[Die Claude-Desktop-Erweiterung installieren](#die-claude-desktop-erweiterung-installieren),
wo jeder Klick beschrieben ist. **Unter Windows ist das der Weg hinein**, und nichts auf
dieser Seite verlangt von Ihnen, ein Terminal zu öffnen.
</Aside>

## Was Sie brauchen

| | Wozu | Woher |
|---|---|---|
| **Ein YNAB-Konto** | avenir-mcp liest und ändert *Ihre* Plans | [app.ynab.com](https://app.ynab.com) |
| **Einen MCP-Client** | die Anwendung, mit der Sie sprechen; sie startet avenir-mcp | Claude Code, Claude Desktop, Cursor, VS Code… |
| **uv** | lädt avenir-mcp und das nötige Python herunter und führt sie in einer isolierten Umgebung aus | der nächste Schritt |

Sie müssen Python **nicht** installieren, das Repository **nicht** klonen und keine
virtuelle Umgebung anlegen: Das alles erledigt uv.

## uv installieren

<Tabs syncKey="os">
  <TabItem label="macOS / Linux">
    In einem Terminal:
    ```bash
    curl -LsSf https://astral.sh/uv/install.sh | sh
    ```
    Oder mit Homebrew: `brew install uv`.
  </TabItem>
  <TabItem label="Windows">
    In PowerShell:
    ```powershell
    powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
    ```
    Oder mit WinGet: `winget install --id=astral-sh.uv -e`.
  </TabItem>
</Tabs>

**Schließen Sie das Terminal und öffnen Sie es erneut**, dann prüfen Sie:

```bash
uv --version
```

Es wird eine Version ausgegeben, etwa `uv 0.12.19`. *Command not found*? Der Installer
fügt uv nur dem `PATH` neuer Terminals hinzu: Öffnen Sie ein neues. Details in der
[Dokumentation von uv](https://docs.astral.sh/uv/getting-started/installation/).

## Ein YNAB-Token besorgen

<Steps>

1. Melden Sie sich bei YNAB **in einem Webbrowser** an, unter [app.ynab.com](https://app.ynab.com) –
   die mobilen Apps zeigen die Entwicklereinstellungen nicht.
2. Klicken Sie oben links auf Ihren Namen, dann auf **Account Settings**.
3. Öffnen Sie **Developer Settings**.
4. Klicken Sie unter **Personal Access Tokens** auf **New Token**, geben Sie Ihr
   YNAB-Passwort ein, dann **Generate**.
5. Kopieren Sie das oben auf der Seite angezeigte Token: eine lange Folge aus Buchstaben,
   Ziffern und Bindestrichen. **YNAB zeigt es nur ein einziges Mal.** Wenn Sie es
   verlieren, legen Sie ein neues an und widerrufen Sie das alte.

</Steps>

<Aside type="danger" title="Behandeln Sie das Token wie ein Passwort">
Ein Personal Access Token kann **jeden Plan Ihres Kontos lesen und ändern**; YNAB bietet
kein Token nur zum Lesen. Fügen Sie es niemals in einen Chat mit einer KI, eine geteilte
Datei, ein Issue oder ein Repository ein. avenir-mcp protokolliert es nie und gibt es nie in
einer Antwort zurück.
</Aside>

## Die Claude-Desktop-Erweiterung installieren

Eine einzige Datei installiert avenir-mcp, das Python, auf dem es läuft, und die
Einstellungen, die es braucht. In diesem Abschnitt gibt es weder ein Terminal noch eine
Konfigurationsdatei, und kein Schritt davon ist unter Windows, macOS oder Linux anders,
außer wo es dort steht.

<LinkButton href="https://github.com/mathbeal/avenir-mcp/releases/latest/download/avenir-mcp.mcpb" icon="download">Download für Claude Desktop</LinkButton>

Es handelt sich stets um die Datei der neuesten Version; welche Version installiert wird,
ist darin vermerkt, und die folgenden Schritte sind unabhängig davon immer dieselben.

<Aside type="caution" title="Führt die Schaltfläche zu einer „Not Found“-Seite?">
Der Release-Workflow fügt die Erweiterung hinzu; daher enthält ein Release, der vor der
Einführung dieses Workflow-Schritts veröffentlicht wurde, keine solche Erweiterung, und
bis zum nächsten Release liefert der Link keine Inhalte. Installieren Sie avenir-mcp in
der Zwischenzeit manuell anhand der
[weiter unten auf dieser Seite beschriebenen Schritte](#prüfen-ob-avenir-mcp-startet);
unter **Assets** ist bei den einzelnen
[Releases](https://github.com/mathbeal/avenir-mcp/releases) angegeben, welche Dateien
jeweils enthalten sind.
</Aside>

<Steps>

1. **Installieren Sie Claude Desktop**, falls noch nicht geschehen, von
   [claude.ai/download](https://claude.ai/download), und öffnen Sie es einmal.

2. **Laden Sie die Erweiterung herunter**, über die Schaltfläche oben oder über
   [diesen Link](https://github.com/mathbeal/avenir-mcp/releases/latest/download/avenir-mcp.mcpb).
   Sie ist etwa 17 kB groß und wird unter dem Namen `avenir-mcp.mcpb` in Ihrem
   Download-Ordner gespeichert.

   Unter Windows warnen Edge oder Chrome Sie möglicherweise, dass die Datei selten
   heruntergeladen wird. Diese Warnung betrifft, wie selten die Datei ist, nicht ihren
   Inhalt: Klicken Sie auf die drei Punkte neben dem Download, dann auf **Keep**. Was
   Sie stattdessen an der Datei prüfen können, steht in
   [SECURITY.md](https://github.com/mathbeal/avenir-mcp/blob/main/SECURITY.md#the-claude-desktop-extension).

3. **Ziehen Sie die Datei auf Settings → Extensions.** Öffnen Sie Claude Desktop und
   wählen Sie anschließend **Settings → Extensions**: Auf diesem Bildschirm werden Ihre
   installierten Erweiterungen aufgelistet, und dort wird die Datei installiert. Nehmen
   Sie die Datei `avenir-mcp.mcpb` aus Ihrem Download-Ordner oder aus der Download-Liste
   Ihres Browsers und ziehen Sie sie auf diesen Bildschirm. Der Installationsdialog wird
   geöffnet.

   Ein Doppelklick auf die Datei könnte ebenfalls funktionieren, sofern Ihr System
   `.mcpb`-Dateien bereits mit Claude Desktop öffnet. Sollte Windows Sie stattdessen
   fragen, **mit welcher Anwendung die Datei geöffnet werden soll**, schließen Sie dieses
   Fenster: `.mcpb`-Dateien sind mit keiner Anwendung verknüpft, und die Suche nach
   `claude.exe` liefert keine Ergebnisse. Ziehen Sie die Datei stattdessen auf den
   Bildschirm **Extensions**.

   Funktioniert keines von beiden? Öffnen Sie auf demselben Bildschirm die
   **Advanced settings** und wählen Sie unter **Extension Developer** die Option
   **Install Extension…**; wählen Sie die Datei aus Ihrem Download-Ordner aus.

4. **Installieren Sie sie.** Das Dialogfeld nennt den Namen der Erweiterung,
   *avenir-mcp for YNAB*, und sagt, was sie tut. Klicken Sie auf **Install**.

5. **Fügen Sie Ihr Token** in das Feld **YNAB personal access token** ein, das Token
   [aus dem Schritt davor](#ein-ynab-token-besorgen). `Strg` + `V` unter Windows und
   Linux, `⌘` + `V` unter macOS. Das Feld verbirgt, was Sie
   einfügen; Claude Desktop verwahrt es dort, wo Ihr System Passwörter verwahrt, und es
   steht in keiner Datei, die Sie öffnen können.

6. **Lassen Sie das Kästchen *Allow changes to your plans* leer**, und speichern Sie
   dann. avenir-mcp beantwortet Fragen und ändert nichts, solange das Kästchen leer
   bleibt. Sie können es später jederzeit ankreuzen, an derselben Stelle.

7. **Prüfen Sie, ob sie da ist.** **Settings → Extensions** führt nun
   **avenir-mcp for YNAB** auf, eingeschaltet.

8. **Fragen Sie es etwas.** Schreiben Sie in einem neuen Gespräch:
   *„Liste meine YNAB-Pläne auf.“* Claude bittet Sie beim ersten Mal, das Tool zu
   erlauben; erlauben Sie es, und die Antwort nennt die Namen Ihrer Pläne. Die
   allererste Antwort dauert ein paar Sekunden länger als die danach, während Claude
   Desktop Python und avenir-mcp holt.

</Steps>

Die Installation ist fertig. Der Rest dieser Seite handelt von den anderen Clients und
von der Installation von Hand; weiter mit
[Ihrem ersten Gespräch](/avenir-mcp/de/getting-started/first-conversation/), oder mit
[Änderungen erlauben](#änderungen-erlauben), wenn der Agent für Sie aufräumen soll.

<Aside type="note" title="Claude Desktop meldet, dass die Erweiterung nicht signiert ist">
Sie ist es nicht: Signieren verlangt ein Code-Signing-Zertifikat, über das das Projekt
nicht verfügt. Was die Datei enthält, und was Sie stattdessen prüfen können, steht in
[SECURITY.md](https://github.com/mathbeal/avenir-mcp/blob/main/SECURITY.md#the-claude-desktop-extension).
Eine Erweiterung, die nicht startet, behandelt die
[Fehlersuche](/avenir-mcp/de/project/troubleshooting/).
</Aside>

| Um | Tun Sie |
|---|---|
| **Das Token zu ändern, oder Änderungen zu erlauben** | **Settings → Extensions → avenir-mcp for YNAB** |
| **Zu aktualisieren** | [Laden Sie die Erweiterung erneut herunter](https://github.com/mathbeal/avenir-mcp/releases/latest/download/avenir-mcp.mcpb) und ziehen Sie sie auf dem Bildschirm **Settings → Extensions** über die bereits installierte Erweiterung; über den Link erhalten Sie stets die neueste Version |
| **Zu entfernen** | Entfernen Sie sie unter **Settings → Extensions**; das Token geht mit ihr |

## Prüfen, ob avenir-mcp startet

Bevor Sie einen Client einrichten, führen Sie avenir-mcp einmal von Hand aus. Dabei wird es
heruntergeladen, und Sie sehen, dass es startet.

<Tabs syncKey="os">
  <TabItem label="macOS / Linux">
    ```bash
    YNAB_API_KEY=ihr-token uvx avenir-mcp
    ```
  </TabItem>
  <TabItem label="Windows">
    ```powershell
    $env:YNAB_API_KEY = "ihr-token"; uvx avenir-mcp
    ```
  </TabItem>
</Tabs>

Der erste Start lädt avenir-mcp und Python herunter: einige Sekunden bis eine Minute.
Danach **wird nichts ausgegeben und der Befehl kehrt nicht zurück** – das ist so gewollt:
avenir-mcp wartet darauf, dass ein Client mit ihm spricht. Drücken Sie **Strg+C**, um es zu
beenden.

Stattdessen erscheint ein Fehler? Siehe [Fehlerbehebung](/avenir-mcp/de/project/troubleshooting/).

## avenir-mcp zu Ihrem Client hinzufügen

Wählen Sie Ihren Client. Diese Konfigurationen sind **nur lesend**: avenir-mcp kann Fragen
beantworten, aber nichts ändern. [Änderungen erlauben](#änderungen-erlauben) folgt danach.
In Cursor, LM Studio und VS Code können Sie es mit einem Klick über die Schaltfläche oben
auf der jeweiligen Registerkarte installieren.

<Tabs syncKey="client">
  <TabItem label="Claude Code">
    In einem Terminal:
    ```bash
    claude mcp add avenir-mcp --scope user \
      --env YNAB_API_KEY=ihr-token \
      -- uvx avenir-mcp
    ```

    | Teil | Bedeutung |
    |---|---|
    | `claude mcp add avenir-mcp` | einen MCP-Server namens `avenir-mcp` registrieren |
    | `--scope user` | für alle Ihre Projekte; ohne diese Option nur für den aktuellen Ordner |
    | `--env YNAB_API_KEY=…` | die Umgebung, mit der avenir-mcp startet |
    | `--` | was folgt, ist der Befehl, der den Server startet |
    | `uvx avenir-mcp` | dieser Befehl |

    Claude Code speichert das, samt Token, in `~/.claude.json`, nur für Sie lesbar.
  </TabItem>
  <TabItem label="Claude Desktop">
    **Die Erweiterung** ist der kurze Weg, der ohne Terminal auskommt:
    [Die Claude-Desktop-Erweiterung installieren](#die-claude-desktop-erweiterung-installieren).

    **Oder von Hand**, wenn Sie die Konfiguration lieber selbst schreiben:

    1. Öffnen Sie Claude Desktop, dann **Settings → Developer → Edit Config**. Dadurch
       öffnet sich `claude_desktop_config.json`:
       - macOS: `~/Library/Application Support/Claude/claude_desktop_config.json`
       - Windows: `%APPDATA%\Claude\claude_desktop_config.json`
    2. Ist die Datei leer, fügen Sie alles Folgende ein. Listet sie bereits Server auf,
       fügen Sie nur den Block `"avenir-mcp": { … }` in das vorhandene `mcpServers` ein,
       mit einem Komma nach dem vorherigen Eintrag.
       ```json
       {
         "mcpServers": {
           "avenir-mcp": {
             "command": "uvx",
             "args": ["avenir-mcp"],
             "env": { "YNAB_API_KEY": "ihr-token" }
           }
         }
       }
       ```
    3. Speichern Sie, dann **beenden Sie Claude Desktop vollständig** – ⌘Q unter macOS
       oder über das Symbol im Infobereich unter Windows – und öffnen Sie es erneut.
  </TabItem>
  <TabItem label="Cursor">
    <LinkButton href={links.cursor} icon="right-arrow">In Cursor installieren</LinkButton>

    1. Klicken Sie auf die Schaltfläche: Cursor fordert Sie zur Bestätigung auf und fügt
       anschließend `avenir-mcp` zu seinen Servern hinzu.
    2. Öffnen Sie **Cursor Settings → MCP**, ersetzen Sie `ihr-token` durch das von Ihnen
       kopierte Token und prüfen Sie, dass `avenir-mcp` eingeschaltet ist.

    Oder von Hand: Legen Sie `~/.cursor/mcp.json` (alle Projekte) oder `.cursor/mcp.json`
    in einem Projekt an oder öffnen Sie die Datei, und fügen Sie hinzu:
    ```json
    {
      "mcpServers": {
        "avenir-mcp": {
          "command": "uvx",
          "args": ["avenir-mcp"],
          "env": { "YNAB_API_KEY": "ihr-token" }
        }
      }
    }
    ```
  </TabItem>
  <TabItem label="VS Code">
    <LinkButton href={links.vs_code} icon="right-arrow">In VS Code installieren</LinkButton>

    1. Klicken Sie auf die Schaltfläche: VS Code fordert Sie zur Bestätigung auf, fragt
       anschließend in einem Passwortfeld nach Ihrem Token und speichert dieses in seinem
       eigenen geheimen Speicher.
    2. Nutzen Sie es aus Copilot Chat im Modus **Agent**.

    Oder von Hand: Legen Sie `.vscode/mcp.json` in Ihrem Arbeitsbereich an. Auch dort
    fragt VS Code nach dem Token, sodass die Datei dieses niemals enthält: Eine Datei aus
    einem Arbeitsbereich lässt sich leicht versehentlich in ein Repository aufnehmen.
    ```json
    {
      "inputs": [
        {
          "type": "promptString",
          "id": "ynab-token",
          "description": "YNAB Personal Access Token",
          "password": true
        }
      ],
      "servers": {
        "avenir-mcp": {
          "type": "stdio",
          "command": "uvx",
          "args": ["avenir-mcp"],
          "env": { "YNAB_API_KEY": "${input:ynab-token}" }
        }
      }
    }
    ```
    Führen Sie anschließend den Befehl **MCP: List Servers** aus, wählen Sie `avenir-mcp`,
    dann **Start Server**.
  </TabItem>
  <TabItem label="Gemini CLI">
    1. Öffnen Sie `~/.gemini/settings.json` (legen Sie die Datei bei Bedarf an) und fügen Sie hinzu:
       ```json
       {
         "mcpServers": {
           "avenir-mcp": {
             "command": "uvx",
             "args": ["avenir-mcp"],
             "env": { "YNAB_API_KEY": "ihr-token" }
           }
         }
       }
       ```
    2. Starten Sie `gemini` und geben Sie `/mcp` ein: `avenir-mcp` erscheint mit seinen Tools. Das Modell ist das, welches Gemini CLI verwendet.
  </TabItem>
  <TabItem label="Codex CLI">
    1. Öffnen Sie `~/.codex/config.toml` (legen Sie die Datei bei Bedarf an) und fügen Sie hinzu:
       ```toml
       [mcp_servers.avenir]
       command = "uvx"
       args = ["avenir-mcp"]
       env = { YNAB_API_KEY = "ihr-token" }
       ```
    2. Starten Sie `codex` und geben Sie `/mcp` ein: `avenir-mcp` erscheint mit seinen Tools. Das Modell ist das, welches Codex verwendet.
  </TabItem>
  <TabItem label="LM Studio">
    <LinkButton href={links.lm_studio} icon="right-arrow">Zu LM Studio hinzufügen</LinkButton>

    Für ein Modell, das auf Ihrem eigenen Rechner läuft – siehe [Ein Modell wählen](/avenir-mcp/de/guides/choose-a-model/#lokale-modelle).

    1. Klicken Sie auf die Schaltfläche: LM Studio fordert Sie zur Bestätigung auf und fügt anschließend `avenir-mcp` zu seiner Datei `mcp.json` hinzu.
    2. Öffnen Sie in LM Studio den Reiter **Program** der rechten Seitenleiste, dann **Install → Edit mcp.json**, und ersetzen Sie `ihr-token` durch das von Ihnen kopierte Token.
    3. Speichern Sie, laden Sie ein Modell, das Tool-Aufrufe unterstützt, und beginnen Sie einen Chat: LM Studio fragt vor jedem Tool-Aufruf nach.

    Oder manuell: Fügen Sie Folgendes in dieselbe Datei `mcp.json` ein:
    ```json
    {
      "mcpServers": {
        "avenir-mcp": {
          "command": "uvx",
          "args": ["avenir-mcp"],
          "env": { "YNAB_API_KEY": "ihr-token" }
        }
      }
    }
    ```
  </TabItem>
  <TabItem label="Andere Clients">
    Jeder MCP-Client, der Server über **stdio** startet, funktioniert. Geben Sie ihm:

    | Einstellung | Wert |
    |---|---|
    | Befehl | `uvx` |
    | Argumente | `avenir-mcp` |
    | Umgebung | `YNAB_API_KEY` = Ihr Token |

    Für Clients, die sich stattdessen mit einer URL verbinden, siehe
    [Über HTTP betreiben](/avenir-mcp/de/guides/run-options/#über-http-betreiben).
  </TabItem>
</Tabs>

<Aside type="tip" title="„uvx not found“ in einer Desktop-Anwendung">
Grafische Anwendungen sehen nicht immer den `PATH` Ihres Terminals. Findet der Client
`uvx` nicht, ersetzen Sie `"uvx"` durch den vollständigen Pfad, den `which uvx` (macOS,
Linux) oder `where uvx` (Windows) ausgibt – zum Beispiel `"/Users/<sie>/.local/bin/uvx"`.
</Aside>

## Änderungen erlauben

Damit der Agent Transaktionen kategorisieren, Geld zwischen Kategorien verschieben oder
Konten abgleichen kann, fügen Sie der Umgebung von avenir-mcp `AVENIR_MCP_WRITE=1` hinzu.

<Tabs syncKey="client">
  <TabItem label="Claude Desktop">
    Aus der Erweiterung installiert: Öffnen Sie
    **Settings → Extensions → avenir-mcp for YNAB**, setzen Sie das Häkchen bei
    **Allow changes to your plans**, speichern Sie, und starten Sie Claude Desktop neu.
    Die Erweiterung setzt die Variable für Sie, es gibt nichts zu tippen.
  </TabItem>
  <TabItem label="Claude Code">
    Entfernen Sie avenir-mcp und fügen Sie es mit der zusätzlichen Variable erneut hinzu:
    ```bash
    claude mcp remove avenir-mcp --scope user
    claude mcp add avenir-mcp --scope user \
      --env YNAB_API_KEY=ihr-token \
      --env AVENIR_MCP_WRITE=1 \
      -- uvx avenir-mcp
    ```
  </TabItem>
  <TabItem label="JSON-Konfigurationen">
    Fügen Sie die Variable neben dem Token hinzu, speichern Sie, dann starten Sie den Client neu:
    ```json
    "env": { "YNAB_API_KEY": "ihr-token", "AVENIR_MCP_WRITE": "1" }
    ```
  </TabItem>
  <TabItem label="Codex CLI (TOML)">
    Fügen Sie die Variable neben dem Token in `~/.codex/config.toml` hinzu, dann starten Sie Codex neu:
    ```toml
    env = { YNAB_API_KEY = "ihr-token", AVENIR_MCP_WRITE = "1" }
    ```
  </TabItem>
</Tabs>

Der Wert muss genau `1` sein. Prüfen Sie: Der Client listet nun **33** Tools statt 19.

| | Nur lesend (Standard) | Mit `AVENIR_MCP_WRITE=1` |
|---|---|---|
| Aufgelistete Tools | 19 | 33 |
| Kategorisieren, budgetieren, abgleichen, anlegen | — | als Vorschau gezeigt, von Ihnen bestätigt, rückgängig zu machen |
| Wenn der Agent etwas missversteht | nichts kann sich ändern | eine Änderung, die Sie bestätigt haben und rückgängig machen können |

<Aside type="caution" title="Wenn Ihr Client Sie nicht fragen kann">
Manche Clients können Ihnen keine Frage stellen (MCP-Elicitation). avenir-mcp gibt dem
Agenten dann einen Einmalcode, und es liegt am Agenten, Ihnen die Änderungen zu zeigen und
auf Ihr Ja zu warten. In [unserer Evaluierung](/avenir-mcp/de/project/evaluation/) hat eines von
acht Modellen, getäuscht durch einen in einer Transaktion platzierten Verwendungszweck, einen
solchen Code eigenmächtig verwendet und seine Änderung danach rückgängig gemacht. Damit nur
Sie bestätigen können, fügen Sie `AVENIR_MCP_REQUIRE_ELICITATION=1` hinzu, wenn Ihr Client
Elicitation unterstützt: Codes sind dann abgeschaltet.
</Aside>

Jede Änderung wird Ihnen gezeigt, bevor sie angewendet wird: siehe
[Sicherheit durch Design](/avenir-mcp/de/concepts/safety/).

## Aktualisieren, entfernen, widerrufen

| Um | Tun Sie |
|---|---|
| **Zu aktualisieren** | `uvx` holt von Zeit zu Zeit selbst neue Versionen; erzwingen Sie es mit `uvx --refresh avenir-mcp`. Die Claude-Desktop-Erweiterung wird aktualisiert, indem Sie sie [erneut herunterladen](https://github.com/mathbeal/avenir-mcp/releases/latest/download/avenir-mcp.mcpb) und auf dem Bildschirm **Settings → Extensions** über die bereits installierte Erweiterung ziehen |
| **Zu entfernen** | `claude mcp remove avenir-mcp --scope user`, oder löschen Sie den Eintrag `avenir-mcp` aus der Konfiguration des Clients. Die Erweiterung entfernen Sie unter **Settings → Extensions**, mitsamt dem Token |
| **Aufzuräumen** | Die einzige Datei von avenir-mcp auf Ihrem Rechner ist sein [Journal](/avenir-mcp/de/concepts/journal/), in `~/.local/state/avenir-mcp/` |
| **Das Token zu widerrufen** | YNAB → Account Settings → Developer Settings → **Revoke** neben dem Token |
