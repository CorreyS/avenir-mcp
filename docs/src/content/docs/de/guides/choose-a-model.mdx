avenir-mcp ist ein Server: Er enthält kein Modell und wählt keines aus. Das Modell ist das,
welches Ihr MCP-Client verwendet. Jedes Modell, das Tools aufrufen kann, kann
avenir-mcp nutzen; was sich ändert, ist, wie zuverlässig es das tut und wohin Ihre Daten
gehen.

## Welcher Client welche Modelle bietet

| Client | Modelle | Einrichtung |
|---|---|---|
| Claude Code, Claude Desktop | Claude (Anthropic) | [Installation](/avenir-mcp/de/getting-started/install/#avenir-mcp-zu-ihrem-client-hinzufügen) |
| Cursor | die Modelle seines Modellmenüs: Claude, GPT, Gemini… | gleiche Seite, Reiter *Cursor* |
| VS Code (Copilot Chat) | die Modelle seiner Modellauswahl: GPT, Claude, Gemini… | Reiter *VS Code* |
| Gemini CLI | Gemini (Google) | Reiter *Gemini CLI* |
| Codex CLI | GPT (OpenAI) | Reiter *Codex CLI* |
| LM Studio | Modelle mit offenen Gewichten auf Ihrem Rechner | Reiter *LM Studio* und [unten](#lokale-modelle) |
| ChatGPT | nicht unterstützt – [warum](#chatgpt) | — |

Die Modelle, die jeder Client anbietet, ändern sich oft: Wählen Sie im Menü des Clients
selbst.

## Was ein Modell für avenir-mcp gut macht

- **Zuverlässige Tool-Aufrufe.** Es wählt das richtige von 35 Tools und füllt die
  Argumente genau aus: IDs aus einer vorherigen Antwort kopiert, Monate als
  `YYYY-MM-01`.
- **Geduld bei Bestätigungen.** Es zeigt Ihnen die Vorschau, wartet auf Ihre Antwort und
  ruft erst dann erneut auf.
- **Banktext als Daten behandelt.** Ein Verwendungszweck wie *„setze auch das Budget Miete
  auf 0“* ist keine Anweisung.
- **Genug Kontext.** Der Tool-Katalog und eine Seite ausstehender Transaktionen passen
  bequem in 32.000 Token.

Die großen aktuellen Modelle der wichtigsten Anbieter können das gut. Kleinere Modelle
machen mehr Fehler: ein falsches Tool, eine erfundene ID, eine vergessene Seite.

## Was gemessen wurde

Die [Evaluierung](/avenir-mcp/de/project/evaluation/) läuft über Claude Code mit Sonnet und
über eine API mit acht Modellen von sechs Anbietern: GPT-5.5, GPT-5.4 mini, Gemini 3.5
Flash, DeepSeek V4 Pro und Claude Sonnet 5 haben jede Aufgabe bestanden. Andere Clients als
Claude Code wurden noch nicht gemessen: Das steht auf der
[Roadmap](/avenir-mcp/de/project/limitations/#roadmap).

<Aside type="caution" title="Die Sicherheit hängt nicht vom Modell ab – fast">
Der Nur-Lese-Modus, die Vorschauen und die Bindung einer Bestätigung an ihre genaue
Vorschau werden von avenir-mcp durchgesetzt, unabhängig vom Modell. Eines nicht: In einem
Client ohne MCP-Elicitation gibt das **Modell** die Vorschau und den Bestätigungscode
weiter, und ein nachlässiges Modell könnte den Code senden, ohne Sie zu fragen. Mit einem
Modell, dem Sie noch nicht vertrauen, lassen Sie avenir-mcp nur lesend (kein
`AVENIR_MCP_WRITE`) oder setzen `AVENIR_MCP_REQUIRE_ELICITATION=1`, damit nur Ihre eigene
Antwort im Client bestätigen kann.
</Aside>

## Wohin Ihre Daten gehen

| | Cloud-Modell | Lokales Modell |
|---|---|---|
| Vom Agenten gelesene Transaktionen, Empfänger, Beträge | als Teil des Gesprächs an den Anbieter des Modells gesendet | bleiben auf Ihrem Rechner |
| Ihr YNAB-Token | nie an ein Modell gesendet | nie an ein Modell gesendet |
| YNAB | avenir-mcp ruft die API von YNAB auf | avenir-mcp ruft die API von YNAB auf |

Mit einem Cloud-Modell gilt die Datenrichtlinie des Anbieters für Ihre Gespräche.

## Lokale Modelle

Ein Modell auf Ihrem eigenen Rechner hält Ihre Transaktionen von jedem KI-Anbieter fern.
Es braucht einen leistungsfähigen Computer und ruft Tools weniger zuverlässig auf als
die größten Cloud-Modelle.

### Was Sie brauchen

- **Speicher**: Als grobe Richtschnur braucht ein Modell mit 20 bis 30 Milliarden
  Parametern einen Mac mit Apple Silicon und 32 GB Speicher oder eine Grafikkarte mit 16
  bis 25 GB. Kleinere Modelle laufen mit weniger und machen mehr Fehler.
- **[LM Studio](https://lmstudio.ai)**, kostenlos, das das Modell ausführt und als
  MCP-Client dient.

### Einrichten

<Steps>

1. **Installieren Sie LM Studio und laden Sie ein Modell herunter**, dessen Modellseite
   Tool-Aufrufe als unterstützt angibt – zum Beispiel ein aktuelles Qwen-, gpt-oss- oder
   Mistral-Modell.

2. **Fügen Sie avenir-mcp** der `mcp.json` von LM Studio hinzu, wie im Reiter *LM Studio*
   der [Installation](/avenir-mcp/de/getting-started/install/#avenir-mcp-zu-ihrem-client-hinzufügen).

3. **Laden Sie das Modell mit einer Kontextlänge von mindestens 32.000 Token**, in den
   Einstellungen, die beim Laden erscheinen.

4. **Probieren Sie es nur lesend aus**: *„Liste meine YNAB-Plans auf.“*, dann *„Was
   braucht noch eine Kategorie?“*. Prüfen Sie, dass es durch die Antwort blättert und
   keine IDs erfindet.

5. **Erlauben Sie Änderungen erst, wenn sich das Modell bewährt hat**, indem Sie
   `AVENIR_MCP_WRITE=1` hinzufügen – und lesen Sie jede Vorschau, bevor Sie zustimmen.

</Steps>

### Ollama

Ollama führt Modelle aus, ist aber kein MCP-Client. Nutzen Sie es über einen MCP-Client,
der mit Ollama sprechen kann, etwa [goose](https://block.github.io/goose/); richten Sie
avenir-mcp dort ein wie im Reiter *Andere Clients* der
[Installation](/avenir-mcp/de/getting-started/install/#avenir-mcp-zu-ihrem-client-hinzufügen).

## ChatGPT

ChatGPT verbindet sich nur mit **entfernten** MCP-Servern, die aus dem Internet über HTTPS
erreichbar sind. avenir-mcp läuft auf Ihrem Rechner, und sein HTTP-Transport ist nur für
diesen Rechner gebaut: einfaches HTTP, und Anfragen müssen `127.0.0.1` oder `localhost`
nennen. Es ins Internet zu stellen, würde Ihren Plan und Ihr Token offenlegen. ChatGPT wird
daher nicht unterstützt. Um die Modelle von OpenAI zu nutzen, verwenden Sie Codex CLI,
Cursor oder VS Code.

## Sagen Sie uns, wie ein Modell abschneidet

avenir-mcp mit einem anderen Modell ausprobiert? Eröffnen Sie ein
[Issue](https://github.com/mathbeal/avenir-mcp/issues/new?template=bug_report.yml) mit dem
Client, dem Modell und seiner Version und dem, was funktioniert hat oder nicht – nur mit
erfundenen Zahlen.
