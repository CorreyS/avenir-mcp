avenir-mcp wordt geconfigureerd met omgevingsvariabelen, die worden ingesteld in het  -blok`env` van uw MCP-client.
De volledige lijst vindt u in [Configuratie](/avenir-mcp/reference/configuration/)].

## Alleen lezen of schrijven

| Instelling | Effect |
|---|---|
| niets (standaard) | 23 leestools; de 14 schrijftools worden niet getoond en zijn niet aan te roepen |
| `AVENIR_MCP_WRITE=1` | alle 37 tools; elke schrijfactie behalve `approve_transactions` en `import_transactions` krijgt een voorbeeld en een bevestiging |

Elke andere waarde (`0`, `true`, `yes`) houdt de server alleen lezend: alleen `1` schakelt
schrijven in.

## Via stdio draaien (standaard)

Je client start avenir-mcp als subproces en praat ermee via zijn standaardinvoer en
-uitvoer. Er luistert niets op het netwerk. Dat doen alle voorbeelden in
[Installatie](/avenir-mcp/nl/getting-started/install/).

## Via HTTP draaien

Voor een client die verbinding maakt met een URL, of om één server te delen tussen meerdere clients op
uw computer. Maak eerst een lang willekeurig token aan, dat de clients moeten tonen:

```bash
export AVENIR_MCP_HTTP_TOKEN=$(openssl rand -hex 32)
```

Start dan de server:

```bash
AVENIR_MCP_TRANSPORT=http \
AVENIR_MCP_HOST=127.0.0.1 \
AVENIR_MCP_PORT=8103 \
YNAB_API_KEY=uw-token \
uvx avenir-mcp
```

Het luistert op  `http://127.0.0.1:8103/mcp`(streamable HTTP). Richt uw client daarop
met het token in een  header`Authorization` — met Claude-code:

```bash
claude mcp add --transport http avenir-mcp http://127.0.0.1:8103/mcp \
  --header "Authorization: Bearer $AVENIR_MCP_HTTP_TOKEN"
```

Via HTTP wordt elk verzoek gecontroleerd voordat het een tool bereikt:

| Controle | Geweigerd met | Stops |
|---|---|---|
| de  header`Host` verwijst naar deze machine (`127.0.0.1`, `localhost`, `::1`) |  `421`| een webpagina die de server bereikt via DNS-rebinding |
| een  header`Origin`, indien aanwezig, is die van deze server |  `403`| een pagina van een andere site, die in uw browser wordt weergegeven |
| `Authorization: Bearer <token>`, met  of`AVENIR_MCP_HTTP_TOKEN` het token dat bij het opstarten wordt weergegeven |  `401`| elk ander programma op uw computer of netwerk |

Het token is **altijd vereist**, ongeacht of het alleen-lezen is of niet. Indien  niet `AVENIR_MCP_HTTP_TOKEN`is ingesteld,
genereert de server bij het opstarten een willekeurig token en geeft dit eenmalig weer op stderr; dit verandert
bij elke opstart, dus stel de variabele in om uw clients een token te geven dat geldig blijft.

<Aside type="danger" title="Bewaar het op uw computer">
Let op`AVENIR_MCP_HOST=127.0.0.1`: het verkeer verloopt via onversleuteld HTTP. Bind
`0.0.0.0` of publiceer de poort nooit op alle interfaces met Docker of een router, en plaats
de server nooit op het internet.
</Aside>

## Waar het journaal staat

Toegepaste operaties worden vastgelegd zodat ze ongedaan kunnen worden gemaakt. Standaard is
het journaal `$XDG_STATE_HOME/avenir-mcp/journal.jsonl`, of
`~/.local/state/avenir-mcp/journal.jsonl` als `XDG_STATE_HOME` niet is ingesteld. Kies een
ander bestand met `AVENIR_MCP_JOURNAL`. Zie
[Journaal en ongedaan maken](/avenir-mcp/nl/concepts/journal/).

## Diagnose

avenir-mcp schrijft diagnoses naar **stderr** – nooit naar stdout, dat in stdio-modus van
het protocol is – op het niveau van `AVENIR_MCP_LOG_LEVEL`, standaard `WARNING`:

| Niveau | Je ziet |
|---|---|
| `WARNING` (standaard) | alleen problemen |
| `INFO` | elke toolaanroep en elk YNAB-verzoek |
| `DEBUG` | alles, inclusief de eigen meldingen van de MCP-bibliotheek |

Een verwachte fout (een verkeerd geschreven maand, een onbekende rekening) wordt op één
regel gelogd; een echte storing houdt haar traceback. Het token wordt nooit gelogd.

## Logs naar een logsysteem sturen

Voor een collector zoals Vector, Fluent Bit, Promtail of een Datadog-agent dient u JSON aan te vragen en
stderr naar een bestand te schrijven dat door de collector wordt gelezen. In de configuratie van de client:

```json
"command": "/bin/sh",
"args": ["-c", "exec uvx avenir-mcp 2>>\"$HOME/.local/state/avenir-mcp/avenir.log\""],
"env": { "YNAB_API_KEY": "uw-token", "AVENIR_MCP_LOG_FORMAT": "json", "AVENIR_MCP_LOG_LEVEL": "INFO" }
```

Elke regel ziet er dan zo uit:

```json
{"time":"2026-09-25T09:12:04.120+00:00","level":"INFO","logger":"avenir_mcp.client","message":"Fetching accounts for plan demo-budget"}
```

Draait de server via HTTP als dienst, dan bewaart de dienstbeheerder stderr: systemd stuurt
het naar het journal, launchd naar het bestand dat `StandardErrorPath` noemt.

`INFO`Vanaf  bevatten berichten uitsluitend identificatiecodes en aantallen — nooit begunstigden, bedragen of
categorieën — zodat logbestanden uw computer kunnen verlaten zonder dat uw financiële gegevens worden meegenomen. Bewaar
`DEBUG`deze voor lokale probleemoplossing.

## Drempel voor suggesties

`AVENIR_MCP_CONFIDENCE_THRESHOLD` (standaard `0.90`) is het deel van de geschiedenis van een
begunstigde dat moet overeenkomen voordat een categorie wordt voorgesteld. Verlaag hem om
meer suggesties te krijgen, die minder vaak kloppen. Zie
[Suggesties](/avenir-mcp/nl/concepts/suggestions/).
